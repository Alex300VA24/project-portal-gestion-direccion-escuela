# Módulo de Bienestar Estudiantil (`app/Modules/Bienestar`)

El módulo gestiona la detección temprana de riesgo académico, la tramitación de servicios estudiantiles (Comedor, Reconsideración, Beca, Duplicados, SISTOC, Talleres deportivos según TUPA UNT), el acompañamiento psicosocial y las estadísticas institucionales bajo la Ley N° 29733 de Protección de Datos Personales.

## Usuarios y Roles de Demostración

Cuentas solo para demostración, con contraseña `Portal2026!`. El middleware `password.change` obliga a cambiarla cuando `seguridad.usuario.debe_cambiar_contrasena` está activo.
