# Preparación del motor CP-SAT

La ejecución institucional se encuentra deshabilitada. Este directorio incluye los paquetes Python `scripts`, `cpsat_hard`, `cpsat_soft` y `exporters` utilizados por el puente; sus 53 archivos fueron comparados con la referencia. El puente recibe JSON por entrada estándar, devuelve `HORARIOS_RESULTADO_V1` por salida estándar y escribe progreso por error estándar. Las dependencias externas deben instalarse por separado; no se incluyen entornos virtuales ni bibliotecas instaladas.

Se verificó Python 3.14.1 y OR-Tools 9.15.6755 en Windows con un entorno virtual fuera del repositorio. Las versiones instaladas para esta prueba se registran en `requirements-prueba-windows.txt`; no es un bloqueo de dependencias de producción. El motor se ejecutó por separado con cuatro actividades ficticias, sin conexión con la instantánea institucional. No se instalaron dependencias globales. La infraestructura y los límites de ejecución requieren coordinación; el límite inicial propuesto es 150 segundos. El futuro ejecutor deberá usar argumentos como lista y rutas controladas, validar entrada y salida, limitar tiempo y tamaño, aislar errores, ejecutarse en una cola y distinguir `OPTIMAL`, `FEASIBLE`, `INFEASIBLE`, `UNKNOWN` y `MODEL_INVALID`.
